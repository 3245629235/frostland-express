# Frostland Express Clean

这是重新创建的干净Godot项目。

当前内容：

- `scenes/title_screen.tscn`：标题界面
- `scenes/main.tscn`：游戏主界面占位符
- `scripts/title_screen.gd`：标题界面逻辑，点击“开始游戏”进入主界面
- `scripts/main.gd`：主界面逻辑，显示背景图和占位文字

使用方法：

1. 打开Godot。
2. 选择“导入”。
3. 选择本文件夹里的 `project.godot`。
4. 导入后按 `F5` 运行。

注意：

- 先不要加雪花、粒子、复杂动画。
- 先确认标题界面能进入主界面。
- 稳定后再逐步添加UI和系统。
