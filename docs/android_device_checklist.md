# Android 真机验证清单（Frostland Express v0.1.0）

> 用途：在无模拟器环境（或模拟器不可用）时，用真机完成发布冒烟。
> APK：`dist/FrostlandExpress.apk`（70.6MB，release 签名，arm64-v8a，包名 com.frostland.express）

## 安装

```bash
adb devices                    # 确认设备（需开启 USB 调试）
adb install -r dist/FrostlandExpress.apk
```

或直接拷贝 APK 到手机安装（需允许「安装未知来源应用」）。

## 冒烟验收点

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 启动应用 | 图标为蒸汽火车头（非 Godot 默认），启动无 Godot 标志，进入标题页「Frostland Express」 |
| 2 | 点「开始」 | 进入主界面；旧档提示「兼容继续 / 重置存档」（首次安装为全新档，无提示） |
| 3 | 编组 | 放入机车+煤水车+任意 2 节车厢，4 名队员，返回主界面 |
| 4 | 登车 | 进入车内视差场景，点「加速」列车行驶，里程/速度/燃料 HUD 更新 |
| 5 | 触控 | 点击小人选中/移动；点击锅炉/物资箱/维修台交互点；双指或按钮缩放画面 |
| 6 | 随机事件 | 行驶 12~20 秒弹事件（暴风雪等），点选项生效 |
| 7 | 站点 | 行驶至 80km 白桦林站：停留收集（+30~60）、维修、补给、继续行驶 |
| 8 | 剧情模式 | 标题页「剧情模式」→ 关卡 1 教学 → 关卡 2 雪狼战（点击敌人射击） |
| 9 | 返回键 | 任意界面按返回：Travel 内打开暂停/返回，不崩溃 |
| 10 | 横竖屏 | 旋转手机，画面自适应不拉伸变形 |
